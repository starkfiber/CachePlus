How it works

Rebuildable things go here.

Choose a mounted volume and a size budget. Run an explicitly disposable task. When it finishes, inspect its exact slot and reclaim it when you need room.

01 / CHOOSE

Use what you have

Name your old drive, USB stick, NAS or cloud mount. CachePlus checks that it is actually mounted before writing.

02 / RUN

Bound the work

Common temporary and build cache paths point at the chosen volume. A free-space floor and soft size cap are monitored.

03 / RECLAIM

Get room back

Only completed CachePlus-owned jobs are eligible. Source, Git, chats and unique files stay persistent.

Local first · MIT licensed

Set it up in minutes.

Python 3.10+ on macOS or Linux. Mount a drive first; CachePlus never formats it.

git clone https://github.com/starkfiber/CachePlus.git
cd CachePlus
python3 -m pip install --user .
cacheplus configure /Volumes/OldSSD --name old-ssd --kind external --limit-gb 100
cacheplus run --disposable my-app -- npm test
cacheplus reclaim

CLI, read-only localhost API and local MCP tools for inspection and explicitly disposable jobs. Native cloud account login and Windows job execution are on the roadmap.
